# LogiChain AI — User Manual & Documentation

> **Autonomous AI Supply Chain Risk Prediction & Mitigation Platform**

LogiChain AI is a polished, enterprise-grade AI workflow simulator and logistics dashboard. It demonstrates how autonomous multi-agent reasoning can ingest logistics documents, cross-reference external events, compute shipping risks, and generate mitigation plans in real time.

This document describes how to set up the project, step-by-step instructions on how to use every feature, and how the underlying agent architecture behaves during a demo run.

---

## 🚀 Installation & Quick Start

### Prerequisites
- Python 3.8+ (Make sure it is added to your PATH environment variable)
- Node.js 18+ & npm

### Step 1: Run the Backend Flask Server
1. Open your terminal and navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install the necessary Python packages:
   ```bash
   pip install flask flask-cors sqlalchemy aiofiles pdfplumber python-docx requests
   ```
3. Start the application:
   ```bash
   python main.py
   ```
4. Verify the backend is up and running by opening: `http://localhost:8000/api/health` in your browser. You should see:
   `{"service": "LogiChain AI", "status": "healthy", "version": "1.0.0"}`

*Note: The SQLite database file (`logichain.db`) is automatically initialized and pre-seeded with 20 dummy shipments, 10 suppliers, 6 port hubs, and 15 global risk incidents.*

### Step 2: Run the Frontend React Application
1. Open a second terminal window and navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install Node dependencies:
   ```bash
   npm install
   ```
3. Launch the Vite local dev server:
   ```bash
   npm run dev -- --port 5173
   ```
4. Open your browser and navigate to: **`http://localhost:5173`**

## 📋 Comprehensive Feature Guide

Here is a step-by-step guide explaining how a user can operate every feature in the interface.

### 1. Running the Initial Risk Analysis
When you load the dashboard for the first time, all shipments have a risk score of `0.0` (indicated as green "Low" risk) because the engine has not run.
1. Locate the **"Analyze All Shipments"** button in the top-right corner of the dashboard header.
2. Click the button.
3. You will see a loading spinner state. The backend is running each of the 20 pre-seeded shipments through the agent workflow against the 15 active global incidents.
4. Once completed, all statistics, charts, tables, and incident lists will refresh. The average risk score will rise, and several shipments will be marked as `Medium`, `High`, or `Critical` risk.

---

### 2. Live KPI Metrics & Charts
- **Active Shipments**: Total tracked logistics containers.
- **High Risk**: Number of shipments currently categorized as High or Critical risk.
- **Open Incidents**: Total active weather, labor, or geopolitical events.
- **AI Recommendations**: Total count of active mitigation choices generated by the AI.
- **Risk Charts**:
  - **Risk Distribution**: Hover over sections of the donut chart to see counts of Low, Medium, High, or Critical shipments.
  - **Risk Score by Port**: A bar chart displaying which ports are currently experiencing the highest average risk levels.
  - **Incident Timeline**: Area charts showing the correlation between active global incidents and overall supply chain risk.

---

### 3. Uploading & Parsing Shipment Documents (Demo Manifests)
The system allows you to upload raw shipping manifest documents and watch the AI process them. Two pre-made test files are included in the root directory: `sample_bill_of_lading.txt` and `sample_purchase_order.txt`.

1. Click the **"Upload Document"** button in the header (or drag files onto the browser window).
2. The upload modal opens.
3. Drag-and-drop or select `sample_bill_of_lading.txt` from the directory.
4. Click **"Analyze Document"**.
5. Watch the **Agent Activity Panel** in the modal. It will animate through the four steps:
   - `Parsing document...` (Agent 1 extracts structured JSON data: IDs, cargo items, weight, ETA, destination).
   - `Checking global events...` (Agent 2 checks weather and congestion issues at the port of Singapore).
   - `Calculating risk scores...` (Agent 3 calculates safety buffers and stockout risks).
   - `Generating recommendations...` (Agent 4 compiles rerouting routes and carrier upgrades).
6. Once completed, a confirmation alert displays. The modal will automatically close, and your dashboard charts and tables will dynamically update with the newly ingested shipment (e.g., shipment `SHP-2024-9001` with High risk).

---

### 4. Running "What-If" Simulations
Use the What-If simulation panel at the bottom of the dashboard to model supply chain adjustments during major global disruptions.

1. Locate the **"What-If Simulation"** card.
2. Select a **Scenario** from the dropdown (e.g., `Port Closure`).
3. Select a **Target Port** to disrupt (e.g., `Singapore`).
4. Adjust the **Severity** slider (1 to 10 scale). A severity of 8+ simulates severe shutdowns.
5. Click **"Run Simulation"**.
6. The simulator will output:
   - The total number of shipments affected.
   - The average increase in risk scores.
   - An executive description of the situation.
   - A side-by-side list of affected shipments showing their original risk level vs. their new simulated risk level, alongside alternative routing options (e.g., *Rerouting via Port Klang*).

---

### 5. Reviewing and Downloading AI Reports
1. Click the **"Reports"** tab in the sidebar navigation.
2. You will see a list of AI-generated threat briefings for every analyzed shipment.
3. Click on any report row to expand details. You can review:
   - **Risk Factors**: Bullet points detailing why the shipment is at risk (e.g., monsoon flooding, gantry crane failures).
   - **Recommendations**: Structured alternative plans showing action type, confidence, cost impact, and estimated business ROI.
   - **Executive Summary**: A summary memo ready for leadership.
4. Click the **"Download"** button to export the report. The browser will download a clean `.txt` file formatted with all details.

---

### 6. Interactive Agent Flow View
1. Click the **"AI Agents"** tab in the sidebar navigation.
2. This displays a live interactive diagram of the directed graph built using **React Flow**.
3. You can click, pan, and zoom around the diagram to inspect how data passes between the input document, the four processing nodes, and the final dashboard state.
4. Read the cards above the graph to understand the responsibilities and logic of each agent.

## 🛠️ Code Architecture & Core Files

### Backend Logic
- **`backend/main.py`**: Defines all REST API routes, parses uploads, runs the agent graph, and executes What-If simulations.
- **`backend/agents/graph.py`**: A custom state machine that executes nodes sequentially and maintains shared context between agents.
- **`backend/agents/document_intake.py`**: Regular expression rules and fallbacks that parse shipping texts into structured Python dictionaries.
- **`backend/agents/watchtower.py`**: Scans the SQLite database for active incidents matching the destination port or region.
- **`backend/agents/risk_prediction.py`**: Mathematical logic to calculate a composite score from weight categories, priority class, and ETA dates.
- **`backend/agents/mitigation.py`**: Selects appropriate options (rerouting, supplier shifts, freight carrier changes) from dictionaries.
- **`backend/seed_data.py`**: Database seeding configurations.

### Frontend Logic
- **`frontend/src/pages/Dashboard.jsx`**: The main page containing grid layouts of charts, metrics, and simulator panels.
- **`frontend/src/components/upload/FileUpload.jsx`**: Drag-and-drop file uploader with animated progress ticks for each active agent.
- **`frontend/src/components/simulation/WhatIfPanel.jsx`**: Select selectors and state managers for simulating shipping delays.
- **`frontend/src/api/client.js`**: Axios-based client for querying backend endpoints.
- **`frontend/src/index.css`**: CSS styling for glassmorphism panels, risk badges, and sidebar indicators.
